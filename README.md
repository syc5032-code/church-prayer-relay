# 🔥 교회 6차 성전 릴레이기도 모바일 웹 현황판

교회 6차 성전 릴레이기도(134일차 ~ 158일차)를 위한 모바일 친화적 웹 현황판입니다.

## 📋 주요 기능
1. **성도용 1시간 기도 신청**:
   - 24개 시간 슬롯(00:00~24:00) 중 원하는 빈자리를 터치하여 간편 신청 (이름, 소속 셀, 비번 4자리, 기도제목)
   - 중복 방지 및 신청 완료된 시간대 즉시 잠금
   - 본인 확인 비밀번호를 통한 취소/수정 가능
2. **관리자 (교역자/간사) 모드**:
   - 우측 상단 모드 전환 (기본 비밀번호: 7777)
   - 빈자리 강제 배정 및 취소 관리
   - 25일간 군단리더별 달성률(%) 및 현황 한눈에 보기
3. **카카오톡 공지문 1초 복사**:
   - [카톡 공지문 복사] 버튼을 누르면 단톡방 공지 양식(신청자 명단 + 남은 공백 시간대)이 클립보드에 자동 복사
4. **내 기도시간 조회 (🔍)**:
   - 이름만 검색하면 본인이 배정된 날짜와 시간대로 즉시 이동
5. **엑셀(CSV) 다운로드**:
   - 하단 [엑셀 다운로드] 버튼으로 전체 25일 릴레이 명단 및 빈자리 현황을 CSV 파일로 저장

## 🚀 사용 및 실행 방법
1. **로컬에서 바로 열기**:
   - index.html 파일을 더블 클릭하여 크롬, 엣지, 사파리 등 브라우저에서 바로 사용 가능합니다.
2. **무료 웹 호스팅 배포 (카톡 링크 공유용)**:
   - GitHub Pages, Vercel, Netlify 등에 index.html 파일을 올리면 즉시 모바일 웹 링크(https://...)로 공유할 수 있습니다.
