뉴사운드교회 성전 릴레이기도를 위한 모바일 친화적 웹 현황판입니다.  
**Supabase(실시간 클라우드 DB)**와 **Vercel(무료 웹 호스팅)**과 연동되어 전 성도 및 교역자가 실시간으로 기도 일정을 함께 확인하고 신청할 수 있습니다.

6. **내 기도시간 조회 (🔍)**: 성함 검색 시 배정된 날짜와 시간대로 즉시 이동

## ☁️ 1. Supabase 클라우드 DB 연동 방법 (약 3분 소요, 100% 무료)

1. **[Supabase](https://supabase.com) 가입 및 새 프로젝트 생성**:
   - 무료 회원가입 후 `New project` 클릭
   - 프로젝트 이름(예: `newsound-prayer`) 및 데이터베이스 비밀번호 입력 후 생성 (지역: `Seoul` 또는 `Tokyo` 권장)
2. **SQL 스키마 실행 (원클릭 테이블 생성)**:
   - 좌측 메뉴에서 **SQL Editor** 클릭 ➔ `New query` 클릭
   - 이 프로젝트 폴더에 있는 `supabase_schema.sql` 파일의 내용을 복사하여 붙여넣고 우측 하단 **[Run]** 버튼 클릭
3. **API 키 확인 및 웹 현황판에 입력**:
   - 좌측 하단 **Project Settings (톱니바퀴)** ➔ **API** 메뉴 이동
   - `Project URL`과 `anon public key`를 복사
   - 웹 화면 상단의 **[☁️ 클라우드 연동]** 버튼 클릭 후 복사한 URL과 Key를 붙여넣고 **[연결 테스트 및 실시간 동기화 시작]** 클릭
   - 연결 성공 후 **[현재 로컬 데이터를 클라우드로 일괄 업로드]** 버튼을 누르면 기존 기본 일정과 샘플 데이터가 클라우드로 즉시 올라갑니다!

## 🚀 2. Vercel 무료 웹 배포 방법 (약 2분 소요)

### [방식 A - 추천] GitHub 연동을 통한 Vercel 자동 배포
1. 본인의 GitHub에 새 저장소(Repository) 생성 (예: `newsound-prayer-relay`)
2. 터미널(PowerShell)에서 아래 명령어로 코드 푸시:
   ```bash
   git remote add origin https://github.com/<본인아이디>/newsound-prayer-relay.git
   git branch -M main
   git push -u origin main
   ```
3. [Vercel](https://vercel.com) 로그인 후 **[Add New...]** ➔ **[Project]** 클릭
4. 방금 올린 GitHub 저장소를 선택하고 **[Deploy]** 클릭!
5. 1분 안에 `https://newsound-prayer-relay.vercel.app` 과 같은 무료 배포 주소가 생성됩니다.

### [방식 B] Vercel CLI로 터미널에서 즉시 배포
터미널에서 아래 명령어를 실행하면 브라우저 로그인 창이 열리며 즉시 배포됩니다:
```bash
npx vercel
```
- 모든 질문에 엔터(기본값)를 누르면 배포 완료 URL이 출력됩니다.
- 프로덕션 배포는 `npx vercel --prod` 를 실행하시면 됩니다.
